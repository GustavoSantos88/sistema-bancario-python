# 🏦 Sistema Bancário em Python

Projeto desenvolvido como parte da formação **Python Developer**, com o objetivo de praticar os principais conceitos da linguagem Python por meio da construção de um sistema bancário.

## 📋 Funcionalidades

O sistema possui as seguintes funcionalidades:

- 💰 Depósito
- 💸 Saque
- 📄 Consulta de extrato
- 👤 Criação de usuários
- 🏦 Criação de contas bancárias
- 📋 Listagem de contas
- 🔐 Identificação de usuários por CPF
- 💳 Controle de limite para saques
- 🔢 Limite de 3 saques por conta
- ✅ Validação das operações

## 🛠️ Tecnologias utilizadas

- Python 3
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Listas e dicionários
- Manipulação de strings
- Fatiamento
- Argumentos posicionais e nomeados
- `*args` e `**kwargs`
- Programação estruturada
